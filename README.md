# Clinical Assessment and Diagnosis · Case Trainer

EMT-level case trainer for PARA603 (AUT paramedicine), anchored to the NZ CPGs.

Students work through each case from dispatch to disposition: scene, primary survey, the four frames, vital signs and EWS, physical assessment, working diagnosis, differentials and disposition. Includes four games (Keep them stable, Time critical, Beat the clock and Hot Seat with a Heads Up option).

Everything is in `index.html`. No sign-in, no server and no tracking. Progress and personal bests are saved only in the student's own browser.

Check all treatment against the current NZ CPGs.

The dyslexia-friendly reading option includes the OpenDyslexic font by Abbie Gonzalez, embedded under the SIL Open Font License 1.1 (see `OpenDyslexic-OFL.txt`).
